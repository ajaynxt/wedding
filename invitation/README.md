# AJAYNXT Wedding Invitation

An isolated interactive 3D wedding invitation prototype served from `/invitation/` on the existing AJAYNXT Wedding GitHub Pages site.

## Experience
- Envelope opens first, followed by the invitation card rising out.
- Card cover rotates in 3D to reveal the inside spread.
- Editable couple names, date, venue, ceremony time, invitation message, and event functions.
- Burgundy, emerald, and midnight cover themes.
- Mobile-responsive layout and reduced-motion support.
- Uses a wedding photograph URL already present in the parent site's `script.js`.

## Preview
After this change is merged to `main` and GitHub Pages finishes deploying:
https://wedding.ajaynxt.com/invitation/

This prototype is front-end only. It does not persist invitation data, create per-couple URLs, store RSVPs, or publish customer-specific pages yet.

The existing homepage and its assets are not modified by this addition.
