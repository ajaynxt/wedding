# AJAYNXT Wedding — 10 Luxury Styles

GitHub Pages-ready luxury Indian wedding planner and photographer concept website.

## Included

- 10 genuinely different luxury hero compositions
- realistic Indian wedding photography
- automatic 60-second hero rotation
- manual style selector
- dark and light modes
- visible color library, search, picker and lock
- visible text library and lock
- font search, selector and lock
- wedding stories gallery
- film and reel previews
- albums and deliverables section
- photography, films, planning, décor and destination services
- three package structures
- destination wedding cards
- interactive availability calendar
- WhatsApp availability enquiry
- structured booking process
- trust and delivery guidance
- mobile action bar
- reduced-motion support
- CNAME for wedding.ajaynxt.com

## Publish

Upload all files to the root of a GitHub repository.

GitHub Pages:
- Settings > Pages
- Deploy from a branch
- Branch: main
- Folder: /(root)

## GoDaddy DNS

- Type: CNAME
- Name: wedding
- Value: ajaynxt.github.io
- TTL: 1 Hour

## Important

This is a portfolio concept. Couple names, wedding stories, packages, dates and deliverables are illustrative. Replace them with verified client information, real portfolio work, written terms, approved reviews and the studio's actual contact information before commercial launch.

The photography loads from Pexels URLs, so an internet connection is required for images.
